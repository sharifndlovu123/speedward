How to set it up
  1. Download a City database in .mmdb form: MaxMind GeoLite2 City (free account and licence from maxmind.com) or DB-IP Lite City (free from db-ip.com, CC BY 4.0). Check the licence before use.
  2. Install the extra: pip install -e ".[geoip]" (the Docker image has it).
  3. Set GEOIP_DB=/path/to/file.mmdb in .env, or for Docker mount the file and pass -e GEOIP_DB=/geo/GeoLite2-City.mmdb. Restart, then run the test again.

The file stays on this server; no lookup leaves it. Addresses shared by a CDN (anycast) still get no square, because their place is uncertain.
